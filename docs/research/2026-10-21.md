## 1. Dependency advisories

Source: rustsec advisory-db commits to 2026-10-21 (https://github.com/rustsec/advisory-db/commits/main/crates), titles plus the pages below.

**Affects rustkube (added to #279, which already asks for a `cargo update`)**
- **rustls-webpki 0.103.9 locked — RUSTSEC-2026-0382 (CVE-2026-111943, added 2026-10-20)**: paths through the distrusted emSign intermediates (private keys now public) are accepted when the trust anchors allow them. Fixed in >= 0.103.16. This raises the target in #279 from 0.103.13 to 0.103.16. https://rustsec.org/advisories/RUSTSEC-2026-0382.html
- **webpki-roots 1.0.6 locked — RUSTSEC-2026-0381** (also 2026-10-20; page not read, presumably the same distrust list). reqwest uses it for roots; take the patched release in the same update. 0383 (webpki-root-certs) is not in the lock. https://rustsec.org/advisories/RUSTSEC-2026-0381.html
- **rustls 0.23.37 locked — RUSTSEC-2026-0346..0349 (2026-10-14), fixed in 0.23.46.** Reachability read from the code and lock:
  - 0346: client-session `Debug` leaks the TLS 1.2 master secret / 1.3 PSK, only through a custom `ClientSessionStore`; we have none. Not reachable. https://rustsec.org/advisories/RUSTSEC-2026-0346.html
  - 0347: buffered application data sent to the outer server after ECH rejection; we do not enable ECH. Not reachable. https://rustsec.org/advisories/RUSTSEC-2026-0347.html
  - 0348: brotli certificate decompression allocates up to 1 GiB pre-auth; no brotli crate in `Cargo.lock`. Not reachable. https://rustsec.org/advisories/RUSTSEC-2026-0348.html
  - 0349: an unauthenticated ServerHello can downgrade later connections to classical key exchange. Concerns the client side (reqwest to webhooks, kubelets, aggregated servers); page not read in full, so reachability is not established. Take 0.23.46 with the rest. https://rustsec.org/advisories/RUSTSEC-2026-0349.html
